# Arbol-de-Huffman
Este código implementa un compresor de texto basado en el algoritmo de Huffman, utilizando estructuras de datos como árboles binarios y colas de prioridad. El programa toma un archivo de texto el cual es llamado original.txt como entrada, calcula la frecuencia de cada carácter, construye el árbol de Huffman y genera los códigos binarios para codificar el texto.

Los resultados se almacenan en el archivo comprimido.txt que contiene los códigos generados y el texto codificado en forma de bits, es decir 0 y 1. En el archivo descomprimido.txt se reconstruye el texto original a partir del archivo comprimido.
